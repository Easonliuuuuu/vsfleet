Stage and commit all current changes using the conventional commits format.

**Input**: Optionally provide a scope or hint after `/commit` (e.g., `/commit socks transport`). If omitted, everything is derived from the diff.

Use the **Skill tool** to invoke `git-commit` with any provided input as context.
